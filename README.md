# TMU Velocity Lab Submissions

Welcome to the TMU Velocity Labs submission repository!

This repository is used by TMU Velocity general members to submit their completed lab implementations for review. The F1TENTH skeleton code and lab instructions should be obtained from the designated F1TENTH lab materials.

## Submission Instructions

### 1. Fork This Repository

Click the **Fork** button in the top-right corner to create your own copy of this repository under your GitHub account.

### 2. Upload Your Completed Lab File

Complete the required lab using the provided F1TENTH skeleton code from the designated lab materials.

Once your implementation is complete, upload **only your completed skeleton code file** to your fork of this repository.

* Place your file in the corresponding lab folder (e.g., `Lab-X/`).
* Keep the original filename where possible.
* Do not upload the entire F1TENTH project, unrelated files, or dependencies.
* Make sure your file contains your completed implementation.

If the corresponding lab folder does not exist, create it before uploading your file.

### 3. Open a Pull Request

Once your file has been uploaded:

1. Open your fork on GitHub.

2. Select **Contribute → Open pull request**, or navigate to the **Pull requests** tab and select **New pull request**.

3. Ensure the base repository is `madesh404/tmu-velocity-labs`.

4. Ensure the base branch is the original repository's default branch and the compare branch is your fork's branch containing your submission.

5. Use the following title format:

   `Lab X Submission - Your Name`

6. In the description, include your name, the lab number, and a brief summary of what you implemented.

7. Click **Create pull request**.

### 4. Review Process

The technical lead will review your submitted file and may leave comments or ask questions about your implementation.

Please monitor your Pull Request for feedback. If changes are requested, update your file in your fork and push the changes to the same branch.

**Do not merge your Pull Request.** Once the review is complete, the team lead will close it without merging your submission into the original repository.

## Submission Checklist

* [ ] Completed the lab using the F1TENTH skeleton code.
* [ ] Uploaded only the completed skeleton code file.
* [ ] Placed the file in the correct lab folder.
* [ ] Opened a Pull Request against `madesh404/tmu-velocity-labs`.
* [ ] Included your name and lab number in the PR title and description.

If you have any questions or issues with GitHub submissions, contact your technical lead.
